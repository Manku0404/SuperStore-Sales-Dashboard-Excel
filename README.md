# 📊 SuperStore Sales Dashboard (Excel)

## Project Overview

This project is an interactive Sales Dashboard developed in Microsoft Excel.

The dashboard helps analyze:

- Total Sales
- Total Profit
- Orders
- Quantity Sold
- Customer Count
- Profit Margin
- Average Discount
- Sales Trends
- Top Products
- Salesperson Performance

## Features

- KPI Cards
- Interactive Slicers
- PivotTables
- PivotCharts
- Business Insights Panel
- Professional Dashboard Design

## Tools Used

- Microsoft Excel 2024
- PivotTables
- PivotCharts
- Slicers
- Excel Tables
- Conditional Formatting
